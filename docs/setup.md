# 从零搭建

Mac 和 Windows 的步骤分开写，不要混着看。

- macOS：[setup-macos.md](setup-macos.md)
- Windows 10/11：[setup-windows.md](setup-windows.md)

两边装完之后都是：COM 口接电脑，USB 口接手机，三台设备在同一个 2.4GHz 局域网，网页 `http://127.0.0.1:8890` 上 `device`、`screen`、`calibrated` 三盏灯为绿。

真机还没验证过的项目在 [hardware-test.md](hardware-test.md)。排错在 [troubleshooting.md](troubleshooting.md)。微信群回复在 [wechat.md](wechat.md)。
