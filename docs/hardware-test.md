# 待实测

本仓库没有 iPhone，也没有 N16R8。不要根据 CI 绿灯推断手机已经能动。

当前要测的手机是 **iPhone 16**（USB-C，iOS 27.2.1）。更早的 Lightning 手机仍然用下面的相机转换器说明。

## iPhone 16（USB-C）

- 第一次把标着 USB 的口接到手机之前，先解锁手机并保持亮屏。
- 用能传数据的 USB-C 对 USB-C 线。只充电的线不会出现鼠标，也刷不了机。
- 如果没有出现鼠标，也没有配件提示：先解锁，再拔掉手机那一侧的线，重新插上。
- 板子标着 **USB** 的口接手机，标着 **COM** 的口接电脑。
- 第一次插入时，若手机问是否允许有线配件，选允许。之后在「设置 → 隐私与安全性 → 有线配件」里确认没有把配件关掉。
- 打开「设置 → 辅助功能 → 触控 → 辅助触控」。
- 控制中心 → 屏幕镜像 → **ESP32 Agent**。若列表里没有，先确认板子已用串口配进同一个 2.4GHz 网络。iOS 27 镜像到这块板载接收器仍没有在本仓库里验证过。

## 按这个顺序

1. **烧录和串口。** N16R8 能写入预编译固件。电脑把 COM 口认成 USB 转串口（可能是 CH343、FTDI 或 CP210x）。`0 status` 有 JSON 回复。Windows 上如果没有 COM 口，按芯片装 FTDI VCP 或沁恒 CH343 驱动。蓝牙配对默认关闭；只有要实验 BLE 时才在串口发 `0 ble pair on`，60 秒内完成，平时不要开。
2. **HID 和供电。** USB 口接上之后，手机把它认成鼠标键盘，辅助触控的圆点会动。iPhone 16 看有线配件提示。Lightning 旧手机用相机转换器，并看会不会弹出「配件耗电量太大」。串口 `rst` 不要变成 brownout。板子上 USB-OTG / IN-OUT 焊盘必须是断开的。
3. **STA 和屏幕镜像。** 配网之后，屏幕镜像列表里能看到 **ESP32 Agent** 并出画面。看不到就重新选一次镜像。画面停住时网页会提示再选一次，不要只刷新浏览器。
4. **7201。** 电脑从 `0 netinfo` 拿到 vtok（不要把其中的 Wi-Fi 密码贴出去）。网页能看到手机画面，不是花屏，静止时也能停在最新的一帧。
5. **指针和中文。** 先等 device 和 screen 两盏灯绿，再校准，点中圆点后第三盏灯才绿。然后把指针移到屏幕中央并停住。输入「谢谢分享」：核对候选和输入框。发送前先过频率和静默；`bubble_visible` 只是你声明看见了新气泡，服务端看不见屏幕。
6. **另一台电脑。** Windows 用 `powershell -ExecutionPolicy Bypass -File ...`。同一块板子换电脑不用重烧；换了网络再跑一次配网。

锁屏后再解锁，镜像会停，需要重新选一次「ESP32 Agent」。
